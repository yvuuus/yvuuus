## <img src="https://raw.githubusercontent.com/MartinHeinz/MartinHeinz/master/wave.gif" width="28" alt="wave"> About me

I build things at the intersection of **machine learning**, **multi-agent AI systems**, and **real-world apps**, from detecting fires in images to routing enterprise workflows through LLM agents.

- 🤖 **AI & Multi-Agent Systems**: LLM-powered agent pipelines with FastAPI, LangChain and RAG (pgvector)
- 👁️ **Computer Vision**: training and fine-tuning detection/classification models (YOLOv5, EfficientNet, SqueezeNet)
- 📱 **Mobile & Web**: cross-platform apps with Flutter/Dart and full-stack PHP
- 📐 **Software Engineering**: SRS documents, backlogs, comparative studies and DB schemas *before* writing code
- 🎮 **Game Dev**: C# team project building a Casbah escape game
