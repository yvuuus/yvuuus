## 🚀 Featured Projects

### 🦋 [Butterfly Agents](https://github.com/team-rocket-ncs/butterfly-agents) · *Python · FastAPI · LangChain · pgvector*
A FastAPI service that runs enterprise workflow capabilities through specialized AI agents. Requests tied to a department (**HR, Finance, Operations**) go through a **3-stage pipeline**: an *Analyst* extracts key fields → an *Auditor* checks them against department rules → a *Closer* produces the final decision.
- 7 registered agents: policy validation, approval recommendation, workflow planning, compliance checks, document analysis, notifications, audit summaries
- RAG layer with **PostgreSQL + pgvector** (cosine-similarity retrieval)
- Provider-agnostic LLM layer: **Ollama, llama.cpp, OpenAI, Anthropic**
- Test suite, Docker dev environment, and a clean modular architecture (`agents/`, `core/`, `knowledge/`, `registry/`, `schemas/`)

### 🔥 [Fire Detect & Classify App](https://github.com/yvuuus/firedetectclassifyapp) · *Python · PyTorch · YOLOv5*
A computer vision app that combines **YOLOv5 object detection** with fine-tuned **EfficientNet-B0** and **SqueezeNet** classifiers to detect and classify fire in images.

### 🚌 [Hafilaty](https://github.com/yvuuus/Hafilaty) · *PHP · SQL · Software Engineering*
A bus transport platform built the way real teams build software: full **SRS (v1 → v2)**, product **backlog**, **comparative study** of existing solutions, database schema (`db.sql`), and iterated **UI designs** (login and passenger interfaces) across 38+ commits.

### 📍 [Bus Tracking App](https://github.com/yvuuus/bus_tracking_app) · *Dart · Flutter*
Cross-platform mobile app for bus tracking.

### 🎮 [Projet-CJRV](https://github.com/yvuuus/Projet-CJRV) · *C#*
A Casbah-themed escape game, built collaboratively with a team.

### 🧩 [Butterfly Orchestration](https://github.com/team-rocket-ncs/butterfly-orchestration) · *TypeScript*
The orchestration layer of the Butterfly platform, built with **Team Rocket**, working alongside the agents service.
